# Documentation

This folder contains the complete project documentation for Qatma Food Delivery App.

The documentation covers:

* Project Introduction
* Problem Definition
* Project Objectives
* Data Gathering and Survey Analysis
* User Requirements
* Competitive Analysis
* Conceptual Model
* Mood Board
* Personas
* Identity Branding
* Site Map
* User Flow
* Figma Design

The document represents the complete Human-Centered Design process followed throughout the project and explains the design decisions made to improve the food ordering experience.
