# Qatma Food Delivery App

## Overview

Qatma is a user-centered food delivery mobile application designed to simplify the online food ordering experience. The project was developed as part of the Designing Human Centered Software course and focuses on improving usability, accessibility, and user satisfaction through a modern UI/UX design process.

The application enables users to browse restaurants, explore menus, customize orders, manage profiles, save addresses, select payment methods, and track orders through an intuitive mobile experience.

---

## Project Objectives

* Simplify the food ordering process
* Improve user experience through intuitive navigation
* Provide efficient order management
* Support real-time order tracking
* Offer multiple payment options
* Enable profile and account management
* Create a visually appealing and user-friendly interface
